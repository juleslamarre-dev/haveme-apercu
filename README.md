# Aperçu — have me productions

## 👉 https://juleslamarre-dev.github.io/haveme-apercu/

Aperçu client de la refonte du site [have-me.com](https://have-me.com/).
Site statique (HTML/CSS/JS), vidéos hébergées sur Vimeo, animations GSAP.

La page est en `noindex` + `robots.txt` bloquant : elle n'est pas indexée par
les moteurs et ne concurrence pas le site en production.

## Mettre à jour

Ce dépôt ne contient que le **résultat publié**. Les sources vivent dans
`~/Projets/haveme` ; pour republier après une modif :

```bash
cd ~/Projets/haveme
./deployer.sh "ce que j'ai changé"
```

Compter ~1 min avant que la page en ligne soit à jour.
